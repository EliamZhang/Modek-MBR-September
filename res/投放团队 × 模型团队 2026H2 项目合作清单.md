# 投放团队 × 模型团队 2026H2 项目合作清单

## 1. 合作背景与目标

围绕投放团队 2026H2 OKR（优化现有渠道提升投放效率、APP 规模与占比提升、新增渠道拓展、优质人群占比提升），以及公司 O2-KR1「建立风险分层与投放优化闭环，提升高质量新客获取效率」（NON SAAC 占比全年不低于 40%），模型侧重点支持 **投放人群分层、归因与回传、ROI 评估、新客风险模型、增量实验评估、新渠道拓展** 等核心方向。

当前投放运营已经具备较强的 Campaign 执行、素材创意与 A/B 测试能力，但存在三个明显缺口：

- **人群智能缺失**：召回触达 13.6k 用户仅带来约 30 Leads，说明「找一批人 → 发触达」的粗放模式转化效率低，缺乏「谁值得买、谁值得花多少钱买」的预测能力；
- **归因与回传尚未闭环**：Tracking ID 刚完成修复，Campaign 归因仍处于进行中，无法稳定回答「这笔 Loan 到底是哪次投放带来的」，回传策略也还未系统化设计；
- **ROI 评估体系缺失**：缺乏统一的 LTV / 买量线测算与渠道级 ROI 监控，预算分配与扩量决策缺少量化依据。

整体合作目标：

- 建立 **Risk × Intent × Value** 新客分层标准并落到投放人群包，实现从「买量」到「买优质人群」的升级；
- 建设投放归因与回传基础设施，通过「巧传」引导媒体算法找到风险可接受、价值可覆盖成本的人群；
- 以**净 LTV 与边际 CPS** 为核心建立投放 ROI 评估体系，让预算分配、扩量与止损决策有量化依据；
- 持续迭代新客风险模型，把风控前置到投放环节（素材、人群、回传），支撑风险表现 7.1% 目标；
- 建设科学的投放实验与增量验证体系，用增量测试回答「没有这波投放，这些人会不会自己来」。

## 3. 项目一：新客分层标准与投放人群体系

### 业务背景

投放团队最大的缺口是「人群智能」——触达能力、A/B 能力都很强，但「到底应该找谁」缺乏标准。现状召回 13.6k 用户仅带来约 30 Leads，说明粗放人群选择效率极低。O2-KR1 明确要求「建立统一的新客客群分层标准，并应用于投放人群及渠道优化」，投放 OKR 同时要求「优质人群占比的提升」。

### 1.1 新客 Risk × Intent × Value 分层标准

| 维度 | 核心问题 | 数据来源 |
| ---- | -------- | -------- |
| Risk | 这个用户能不能借、会不会还？ | 新客 PD 模型、征信 / 替代数据 |
| Intent | 这个用户现在想不想借？ | 广告点击、浏览 / 申请行为、搜索意图 |
| Value | 这个用户值不值得买？ | 预估 LTV、收入 / 负债画像 |

形成分层示例：

- 低风险 × 高意愿 × 高价值 → **优质人群**：保量提价，核心转化目标
- 低风险 × 低意愿 → 常规人群：标准出价
- 中风险 × 高意愿 → 定价 / 观察人群：控制出价
- 高风险 × 高意愿 → 风险控制人群：不出价或素材劝退（素材即风控）

### 1.2 分层结果在投放环节的应用

- **人群包**：分层结果定期刷新输出投放人群包与 Lookalike 种子人群，供媒体定向直接调用；
- **渠道 × 人群匹配**：不同渠道人群结构差异明显（Google 需求拦截 / Meta 人群圈选 / TikTok 兴趣引爆 / 应用商店高质量），分层结果指导渠道与人群的匹配策略；
- **出价策略**：优质人群提高出价保量、边缘人群降低出价控制成本——买量线分层管理（与项目三联动）；
- **素材策略**：素材本身是第一道筛选器，分层结果指导素材卖点（优质人群打信任 / 透明，边缘人群打场景）；
- **与回传联动**：分层结果作为回传筛选的输入（见项目二 2.2）。

### 1.3 优质人群识别（画像 AI 智能体，P1）

依托「澳洲用户多维画像 AI 智能体」（模型团队重点工作 #7）：融合用户属性、交易行为、收入负债、风险表现等多源数据，每月输出人群洞察与优质人群特征，支撑「优质人群占比提升」的持续迭代。

### 主要交付物

1. 新客 Risk × Intent × Value 分层标准与用户级标签
2. 投放人群包定期刷新 Pipeline（含 Lookalike 种子人群）
3. 渠道 × 人群匹配与出价策略建议
4. 优质人群画像月度报告

## 4. 项目二：投放归因与回传基建

### 业务背景

投放的每一笔预算，最终都要能回答「带来了什么」。当前 Tracking ID 刚修复、归因仍进行中；而 CPS 稳定基础上的 leads 增长，前提是「知道钱花得值不值」。同时，oCPX 模式下回传是媒体算法学习的命脉——**我们回传什么，媒体就帮我们找什么人**。本项与模型团队重点工作 #2「投放归因与 ROI 评估体系」直接对应。

### 2.1 Tracking 与归因基建

- 打通 **曝光/点击 → 下载 → 注册 → 申请 → 授信 → 放款** 完整事件链路，统一各环节 ID 与时间戳；
- **统一归因窗口**：信贷转化周期长，在 MMP 层面统一 30 天点击窗口，避免渠道价值被系统性低估；
- **归因基准**：以 MMP 数据为准、不迷信媒体自报（自归因渠道存在「抢功」问题）；内部引入多触点归因（MTA）识别「助攻」渠道；
- **iOS 双轨**：IDFA 确定性归因（约 14%–35% 授权用户，用于洞察）+ SKAN 聚合归因（用于结算）；设计转化值（Conversion Value）区分注册 / 申请 / 授信 / 放款深度，两类数据不做去重。

### 2.2 回传策略体系：从「扣量」到「巧传」

回传决定媒体算法「学什么样的人」。扣量的短期收益以长期模型损伤为代价，正确方向是巧传：

- **分层加权回传**：高价值 / 优质人群强化回传权重，让模型记住「什么是好用户」；
- **前置回传**：基于行为预测转化、提前回传信号，加速冷启动学习（冷启动 CPM 可降 20%–40%）；
- **关键行为替代**：真实放款样本不足时，用申请 / 授信等强相关行为作为代理事件回传；
- **分阶段策略**：冷启动期以浅层事件（注册 / 申请）为主保样本量 → 模型收敛期逐步增加深层事件（授信 / 放款）比例 → 稳定期多节点回传、差异化加权；
- **稳定性原则**：回传策略保持相对稳定，频繁调整会让买量模型陷入非稳态。

### 2.3 深层转化事件回传（CAPI）

- 通过 CAPI（Conversions API）等服务端通道补传授信、放款等深层事件，绕开 iOS 隐私限制，让系统「重新看见」真实转化；
- **风险过滤回传**：与风险团队联动，将 PD 分过低的人群从转化正样本中剔除——引导媒体算法向「风险可接受」的人群收敛。这是「优质人群占比提升」的关键杠杆。

### 主要交付物

1. 投放全链路事件 Data Mart 与归因宽表
2. 统一归因窗口与归因规则配置（含 iOS 双轨与转化值设计）
3. 回传策略方案与分阶段实施计划（含 CAPI 深层事件回传）
4. 回传策略实验记录与效果评估

## 5. 项目三：投放 ROI / LTV 评估与预算优化

### 业务背景

预算 = 目标放款量 × CPS，而 CPS 的合理上限由用户价值决定。当前缺统一的 ROI 评估体系，预算分配与扩量决策缺少量化依据。需要建立「LTV → 买量线 → 渠道分配 → 扩量 / 止损」的完整预算逻辑。

### 3.1 新客 LTV 测算与买量线制定

- **净 LTV = 毛 LTV（利息收入）− 资金成本 − 坏账损失 − 运营成本**；
- **买量线 = 净 LTV × 目标利润率系数**（扩张期系数可 >1 换规模，盈利期 <1）；
- 三条预算控制线：
  - 盈亏平衡线：获客成本 = 用户 LTV（值不值得买）；
  - 目标 ROI 线：获客成本 = LTV ÷ 目标 ROI（应该花多少钱买）；
  - 止损线：预设最大允许成本，超过即降预算 / 暂停 / 优化（什么时候停）；
- 回本周期测算，支撑现金流与预算节奏；
- **分人群买量线**：优质人群买量线高于边缘人群，支撑差异化出价（与项目一联动）。

### 3.2 渠道 × 人群 × 素材 ROI 与边际 CPS 监控

- 平均 CPS 看当前效率，**边际 CPS 看扩量是否值得**：边际 CPS < 净 LTV 可继续放量；边际 CPS > 净 LTV 停止扩量或优化人群 / 渠道；
- 渠道健康度监控：渠道集中度、新老客占比、渠道级通过率 / 首逾率 / LTV；
- 素材级 ROI：素材不仅要看 CTR，还要看后端（通过率、首逾、复借）——「CTR 高但首逾率高」的素材是失败的素材；
- 学习期监控：新计划学习期（约 50 个转化）消耗慢属正常，避免误判为跑不动而错误加价。

### 3.3 投放异动诊断与 Dashboard（P1）

- **消耗异动诊断**：出价过低 / 计划学习期 / 定向过窄 / 竞争加剧；
- **CPS 异动诊断**：市场变贵（竞争） / 风险通过率下降（流量质量） / 借款意愿变弱；
- 投放 Dashboard：消耗、漏斗、CPS、风险指标、渠道对比，本月 vs 上月 vs 目标，数据质量核查。

### 主要交付物

1. 新客 LTV 测算模型与买量线管理机制（分人群 / 分渠道）
2. 渠道 × 人群 × 素材 ROI 监控报表（含边际 CPS）
3. 投放 Dashboard 与异动诊断手册

## 6. 项目四：新客风险模型与投放质量管控

### 业务背景

「投放带来的人，风控能接住多少」是核心命题。O2-KR1 要求持续迭代新客风险模型、增强头部及尾部风险区分度。获客成本越高，风控前置的价值越大：素材决定「谁来」——「No credit check」类素材天然吸引资质差的用户，**素材本身就是第一道风控**。

### 4.1 新客 PD 模型迭代

- 增强头部（优质）与尾部（高风险）区分度，支撑授信通过率 × 风险平衡（风险表现 7.1% 目标）；
- 新客风险分层与投放人群分层联动（Risk 维度直接进入项目一的分层标准）。

### 4.2 投放侧风险监控

- 按渠道 × 素材 × 人群维度监控通过率、FPD、逾期率——识别「CTR 高但首逾率高」的素材与渠道；
- 素材级风险预警与下线机制；
- 回传人群质量监控：回传样本的 PD 分布是否漂移（回传策略失效的早期信号）。

### 4.3 风控前置到投放环节（P1）

- **素材筛选**：合规 + 质量双审（合规红线：禁止「保证通过 / 无信用检查」类话术，利率透明展示）；
- **回传筛选**：低风险质量人群不作为转化正样本回传（与项目二联动）；
- **远期评估**：RTA 实时前置筛选（广告曝光前通过 API 判断是否参竞）的平台支持度与落地条件。

### 主要交付物

1. 新客 PD 模型迭代版本与监控报告（PSI / 区分度）
2. 渠道 × 素材风险监控报表与预警机制
3. 风控前置方案（素材审核规则、回传筛选规则、RTA 可行性评估）

## 7. 项目五：投放实验评估与增量验证

### 业务背景

团队 A/B 实验多但成功率一般；信贷转化周期长、iOS 归因不准，很多「结论」实际是归因偏差。2026 年媒体侧自动化（Meta Advantage+ / Google PMax）已成为默认形态——「素材即定向」，人工操控空间收窄，优化师的角色转向策略制定与实验评估。科学的实验与增量验证体系，是投放团队与数据 / 模型团队合作的差异化价值所在。

### 5.1 投放 A/B 实验规范

- **每次只测一个变量**（素材 / 定向 / 出价 / 版位）；
- **样本量与显著性**：p<0.05，每组至少 1000 个点击；信贷转化率低（1%–5%），测试周期至少覆盖一个完整转化窗口（2–4 周）；
- **后端指标优先**：赢家是「授信通过率 / 首逾率 / 放款」更好的那个，不是 CTR 更好看的那个；
- **iOS 归因不准的应对**：设备级分流（归因偏差对两组对称）、只看相对差异不看绝对值、Android 作参照系、SKAN 转化值分布对比。

### 5.2 增量测试（Incrementality，P1）

归因回答「功劳归谁」，增量回答「**没有这波投放，这些人会不会自己来**」。

- **Geo-lift**：相似区域对照（测试区正常投放 vs 控制区暂停 / 减投），观察期 4–8 周；
- **Holdout**：人群级 holdout 组，测量触达的真实增量；
- 应用场景：渠道真实增量验证、自然量占比校准、品牌词 / 再营销投放价值评估、预算再分配依据。

### 5.3 投放监控与异动诊断 Agent（P1）

- 每日监控消耗、CPS、漏斗、素材衰减（CTR 下降 1.5% 触发迭代提醒）；
- 异动自动归因（消耗 / CPS 维度）并输出诊断结论；
- A/B 实验自动显著性检验与标准实验报告。

### 主要交付物

1. 投放 A/B 实验规范手册（含 iOS 特殊处理）
2. 增量测试方案与首轮 Geo-lift / Holdout 结论
3. 投放监控 Agent Prototype

## 8. 项目六：新增渠道评估与 APP 规模化（P1）

### 业务背景

OKR 要求新增渠道拓展业务规模、APP 规模与占比持续提升。金融类是 2026 年获客成本最高的品类之一，新渠道不能拍脑袋上量，需要「小预算测试 → 评估 → 放量」的标准框架；同时 APP 占比提升需要把 Web → APP 转化与激活人群识别做深。

### 6.1 新渠道测试评估框架

- **测试期管理**：起量期（1–7 天）观察消耗速度与学习期表现；放量判断：边际 CPS < 净 LTV；
- **渠道评分卡**：量级、成本、质量（通过率 / FPD）、留存 / 复借、合规；
- **冷启动回传**：新渠道以浅层事件起步保样本量，随学习收敛逐步切换深层事件；
- **新渠道人群结构分析**：与现有渠道人群分层对比，识别差异化增量人群。

### 6.2 APP 转化与激活分析

- **Web → APP 转化漏斗**：下载 → 激活 → 注册 → 申请各环节流失点分析（依赖 Tracking 关联，与项目二联动）；
- **非 APP → APP 人群识别**：激活意愿模型输出优先触达人群；
- **应用商店优化数据支持**：ASA / Google Play 关键词与转化数据回流分析。

### 主要交付物

1. 新渠道测试评估框架与渠道评分卡
2. Web → APP 漏斗分析报告
3. APP 激活意愿人群包

## 10. 实施优先级与能力框架

**第一阶段（P0）**：新客分层标准与人群包、归因与回传基建、LTV / 买量线与 ROI 监控、新客 PD 模型迭代、渠道 × 素材风险监控、A/B 实验规范。

解决：**找谁买（人群）、花多少钱买（买量线）、买来值不值（归因 / ROI）、买的人好不好（风险）。**

**第二阶段（P1）**：增量测试、新渠道评估框架、APP 激活分析、投放监控 Agent、画像 AI 智能体、风控前置（RTA 评估）。

解决：**渠道真实价值怎么验证、新渠道怎么科学拓展、APP 占比怎么提升、日常监控怎么自动化。**

最终沉淀为四层能力：

**Layer 1｜Data Foundation**：投放曝光点击 × 转化漏斗 × 风险表现 × 财务数据

**Layer 2｜Customer Intelligence**：Risk × Intent × Value × 新客 LTV × 优质人群画像

**Layer 3｜Decision Engine**：Audience × Channel × Creative × Bid × Budget

**Layer 4｜AI Agent**：Monitor × Diagnose × Recommend（投放异动、素材衰减、实验评估）

形成「数据 → 人群决策 → 投放执行 → 回传优化 → 效果评估 → 预算迭代」的投放增长闭环，实现从**买量驱动**到**价值与人群驱动**的升级。
