## 1. 框架目标与边界

### 1.1 目标

建立一套标准化的营销分析与决策体系，实现三个目标：

1. **分析更快**：监控与计算通过看板自动完成，从"每次手动拉数"变为"每周打开看板即有结论"。
2. **判定一致**：所有渠道用同一套目标带宽与状态判定规则，避免不同人得出不同结论。
3. **方法可复用**：深度分析方法标准化为可迁移的 skill，推广到每个 Campaign 时不必从头摸索。

### 1.2 边界

- 本框架解决"**目标设定 → 状态监控 → 差距诊断 → 行动建议**"，不替代具体投放动作的执行。
- 本框架不依赖任何 AI / 模型能力，当前版本全部可由 SQL + BI 看板 + Excel 实现。预测类能力（如事前 LTV 预估、Campaign 最终 CPS 预测）属后续独立课题，不在本框架范围内。
- 文中数值均基于 Pmax Value Campaign、54 周数据，推广至其他 Campaign 需重新计算（见第 5、9 节）。

### 1.3 框架构成

| 模块 | 分工 | 属性 |
| --- | --- | --- |
| 模块一：营销 KPI 目标管理框架 | 定目标、定状态、定行动 | 管理 / 治理型 |
| 模块二：深度投放分析框架 | 算效率、归因效果、沉淀知识 | 分析 / 诊断型 |

**两者关系**：模块一提供"标准"（目标带宽、状态判定、优先级），模块二提供"方法"（边际成本、动作效果、学习期），为模块一的异常诊断提供依据，并把结论沉淀为可复用的优化知识库。

### 1.4 整体流程

```
设定目标（模块一渠道分配）
   → 每周监控（模块一状态判定）
   → 未达标时诊断（模块二深度分析）
   → 生成行动建议（模块一优先级）
   → 执行与复盘 → 写回知识库 → 方法迭代
```

## 2. 模块一：营销 KPI 目标管理框架

### 2.1 定位

将 Y26 总体 KPI 拆解到核心渠道，划分低 / 中 / 高目标区间（目标带宽），搭配红 / 黄 / 绿三色监控与差距诊断流程。

### 2.2 步骤一：渠道目标区间设定

**输入**：核心渠道清单、年度总体目标、各渠道历史 Leads 数据。

**设定方法**（四条规则，按顺序执行）：

1. **历史加权**：渠道基线值 = 0.5 × 近 3 月月均 + 0.3 × 近 6 月月均 + 0.2 × 近 12 月月均。
2. **增长校准**：目标中值 = 基线值 ×（1 + 年度增长系数）。
3. **带宽设定**：低 / 高目标按渠道历史波动设定宽度——波动小的渠道带宽窄，波动大的带宽宽。具体系数在试运行阶段校准（见 7.3）。
4. **结构对齐（硬性约束）**：各渠道低值合计 ≤ 总目标 ≤ 各渠道高值合计。不满足时优先调整带宽最宽的渠道。

**输出字段**：渠道、定位（付费 / 免费、核心 / 补充）、占比低 / 中 / 高、月 Leads 目标。

> **当前样本值（Y26 校准结果，示例性质，非通用参数）**

| 渠道 | 定位 | 占比低 | 占比中 | 占比高 | Leads/月 |
| --- | --- | --- | --- | --- | --- |
| Google | 付费—核心量 | 47.5% | 50.0% | 52.5% | 32,800 |
| Organic | 免费—质量王牌 | 27.0% | 29.0% | 31.0% | 19,000 |
| Owned Channels | 免费—内部资产 | 9.5% | 11.0% | 12.5% | 7,200 |
| Lead Partner | 付费—渠道商 | 7.5% | 8.5% | 9.5% | 5,600 |
| Bing | 付费—效率补充 | 0.5% | 0.7% | 0.9% | 460 |
| GEO | 免费—新兴增长 | 0.5% | 0.7% | 1.0% | 460 |
| Tiktok / Meta | 付费—实验性 | 0.1% | 0.1% | 0.2% | 65 |
| **合计** | | **92.6%** | **100.0%** | **107.6%** | **65,570** |

> **结构性观察**：Google + Organic 合计约 79% 的 Leads——任何调整计划都需优先处理这两个渠道。

### 2.3 步骤二：监控机制（状态判定）

**三状态定义**：

| 状态 | 判定条件 | 行动 |
| --- | --- | --- |
| 🟢 绿色（安全） | 在目标带宽内 且 在历史 1σ 范围内 | 日常监控 |
| 🟡 黄色（关注） | 偏离目标 5–15% 或 偏离历史 1–2σ | 调查原因，下期继续观察 |
| 🔴 红色（警报） | 偏离目标 >15% 或 偏离历史 >2σ | 升级上报，制定纠正计划 |

**两种判定方法**：

- **方法 A — 统计法**：基于近 12 个月历史周度数据的标准差 σ 与均值。判定依据为"实际值偏离历史均值的 σ 倍数"。各渠道 σ 不同：Google 区间较窄（CoV ≈ 8%），GEO 较宽（CoV ≈ 55%）。
- **方法 B — 目标锚定法**：基于步骤一的目标带宽。在带宽内 = 绿；偏离 5–15% = 黄；偏离 >15% = 红；偏离 <5% 视为绿。

**复合规则**：

1. **取严**：A、B 两法同时计算，取更严重的状态——同时覆盖"偏离计划"与"偏离历史常态"两类问题。
2. **慢性问题升级**：连续两月黄色 → 自动升级为红色；连续两月红色 → 标记为严重级。

> 阈值（5–15%、1–2σ）为默认参数，可在季度校准中调整，调整须记录理由。

### 2.4 步骤三：差距诊断与行动建议

**诊断字段**：Leads 目标、Leads 实际、缺口 %、CPFL Δ、Green% Δ、状态（框架判定色）、根因、建议行动。

**优先级规则**：P0 = 缺口大且伴随成本恶化或结构性问题，需当周响应；P1 = 需要动作但可排期处理。

> **样本（三月诊断结果，示例性质）**

| 渠道 | 目标 | 实际 | 缺口% | CPFL Δ | Green% Δ | 状态 | 建议行动 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Google | 30,269 | 25,684 | -15.1% | +14.8% | -4pp | 🔴 | 竞价复核 + 素材优化；关注 CPFL 恶化，必要时调 tROAS |
| Organic | 17,556 | 12,823 | -27.0% | — | -0.4pp | 🔴 | SEO 专项诊断（量问题，非质量问题），排查自然流量下滑根因 |
| Lead Partner | 5,146 | 4,211 | -18.2% | +38.5% | -6pp | 🔴 | 最大成本恶化源（$24.7k）；审计合同条款，质量低于承诺则退出 |
| Owned Channels | 6,659 | 5,975 | -10.3% | — | -2pp | 🟡 | 增加投放频次与触点；作为 LP 预算转移承接渠道 |

**小渠道处理规则**：合计占缺口比例小（<5%）的渠道，即使标红也不优先处理——待主渠道稳定后专项处理。

**行动顺序（样本）**：Lead Partner 审计（P0）→ Organic SEO 诊断（P0）→ Google 竞价复核（P1）→ Owned Channels 承接（P1）。

### 2.5 关键规则汇总

| 规则 | 内容 |
| --- | --- |
| 目标带宽设定 | 历史加权（0.5/0.3/0.2）+ 增长校准 + 波动带宽 + 结构对齐约束 |
| 状态判定 | 统计法（σ）与目标锚定法（带宽）并行，取严 |
| 状态升级 | 连续 2 月黄 → 红；连续 2 月红 → 严重级 |
| 差距诊断 | 缺口 % + CPFL Δ + Green% Δ 三维联动 |
| 行动优先级 | P0（当周响应）/ P1（计划处理）分级 |

### 2.6 输出物

- 分渠道目标带宽表（季度校准）
- 周度状态看板（红 / 黄 / 绿 + 缺口字段）
- 差距诊断表（异常渠道 + 根因 + 行动 + 责任人 + 截止时间）

## 3. 模块二：深度投放分析框架

### 3.1 定位

基于单 Campaign 的长周期历史数据做效率与效果归因，产出该 Campaign 的优化知识库，分析方法标准化为可复用 skill，推广到其他 Campaign。

### 3.2 分析维度总览

| 维度 | 内容 | 状态 |
| --- | --- | --- |
| 1. 边际 CPFL | 每多投入 1 美元的真实成本，及其与平均成本的关系 | ✅ 已覆盖 |
| 2. 调整动作效果 | 不同幅度预算调整对 CPFL 的影响（幅度分档） | ✅ 已覆盖 |
| 3. 学习周期 | 各类动作上线后所需学习期（CPFL 稳定时间） | ✅ 已覆盖 |
| 4. 预算消耗时长 | 预算消耗节奏与效率的关系 | ⬜ 方法已定义，样本数据待补充 |

### 3.3 维度一：边际 CPFL

**计算定义**：

- 边际 CPFL = 相邻两个支出水平之间，成本增量 ÷ 完成借款增量。
- 平均 CPFL = 历史累计总成本 ÷ 总完成借款数（参考线）。

**判定要点**：

- 边际 CPFL 是决策关注指标，平均 CPFL 仅作参考。
- 边际线与平均线越分开，说明继续加投的边际收益递减越明显。

> **样本结论（Pmax Value）**：当前位于 ~$25k/周；该位置边际比平均高约 $90，每多投一笔比历史均价贵约 50%；弹性 0.45（每多花 $1 平均只换 $0.45 增量 Loans 价值）。建议将上限锚定在 $25k，先做实当前规模再考虑扩量。

### 3.4 维度二：调整动作效果（幅度分档）

**分档定义（默认参数）**：

| 档位 | 预算调整幅度 |
| --- | --- |
| T1 | <5% |
| T2 | 5–10% |
| T3 | 10–15% |
| T4 | 15–20% |
| T5 | ≥20% |

**统计口径**：按档位 × 方向（升 / 降）统计调整后 CPFL 变化与波动变化。

**共发动作清理（必做步骤）**：只保留"无同周大动作"的预算调整事件，剔除同期伴随以下任一情况的样本——tROAS 变更、转化目标变更、着陆页修改、多次预算调整。否则结论会被共发干扰污染。

> **样本结论（清理后 20 个有效事件，原 47 个）**

| 档位 × 方向 | 清理后 N | 结论 |
| --- | --- | --- |
| T1 <5%（任意方向） | 0 | 撤回原结论（样本被共发动作污染） |
| T2 5–10% 升 | 5 | ✅ 安全且稳定 |
| T2 5–10% 降 | 5 | 小幅波动上升 |
| T3 10–15% 升 | 4 | ✅ 反而最稳定（比原版更强的结论） |
| T3 10–15% 降 | 1 | 样本不足（n=1），不下结论 |
| T4 15–20% 升 | 1 | 撤回原结论（仅 1 个样本） |
| T4 15–20% 降 | 0 | 无有效样本 |
| T5 20%+ 升 | 1 | 样本不足，不下结论 |
| T5 20%+ 降 | 3 | 小幅波动，与原版方向一致 |

> **样本结论**：T2（5–10%）安全，是最常用档位，波动小；T3 升（10–15%）反而最稳（波动降 11pp），中等升幅可能是新的"甜蜜点"；T1 / T4 升的原始结论被同周大动作（尤其 tROAS 极端波动）污染，已撤回。
>
> **复核修订（源文注明）**：① 共发动作干扰已确认——5 个 T1 事件全部与 tROAS 变更或多次预算调整同周发生；② 旺季效应已检查——54 周内仅 4 个事件落在 10–12 月旺季且分布在 T2/T3，不集中污染单一档位，旺季干扰存在但有限。

**样本量规则**：清理后 n<3 的档位不下结论，标注"样本不足"。

### 3.5 维度三：学习周期

**判定规则**：动作生效后，当 CPFL 周环比变化幅度 <1σ 且连续 2 周满足时，视为学习期结束；观察窗口上限 12 周，超窗未稳定则标记"未收敛"。

> **样本值（各类动作平均学习期）**

| 动作 | 平均学习期 |
| --- | --- |
| 转化目标变更 | 3.3 周 |
| 负关键词 | 2.2 周 |
| tROAS 变更 | 2.0 周 |
| 预算 升 | 1.6 周 |
| 预算 降 | 1.3 周 |
| Asset 新增 | 0.8 周 |
| 受众信号 | 0.7 周 |
| 暂停 / 启用 | 0.7 周 |
| 着陆页 | 0.4 周 |

> **样本观察**：转化目标变更最具破坏性（一致 3–4 周学习期）；tROAS 极端值触发长学习期（650%→1050% 触发 6 周，小幅 <15% 仅 1 周）；预算调整通常 1–2 周（T4 升例外，达 2.8 周）；素材 / 着陆页几乎无学习期，可随时进行。
>
> **操作规则**：修改转化目标后 14 天内暂停其他变更；避免 tROAS 跨档大幅跳动。

### 3.6 维度四：预算消耗时长

**方法定义**（源材料未提供样本数据，以下为分析口径）：

1. **消耗节奏**：按日统计预算消耗占比分布，识别"前期消耗过快 / 后期不足"或"消耗平缓"模式。
2. **消耗时长**：计算每次加预算后"预算消耗完所需天数"的序列，统计均值与波动。
3. **与效率的关联**：将消耗时长与同期 CPFL 对照，判断是否存在"消耗过快 → 效率恶化"或"消耗过慢 → 曝光不足"的模式。

**输出**：该 Campaign 的预算消耗画像（节奏类型 + 时长基准 + 与 CPFL 的关联结论），写入知识库。

> **样本数据待补充**：需以实际数据填充后形成结论（见第 9 节）。

### 3.7 产出物：知识库 + 可复用 skill

- **优化知识库**：每个 Campaign 一个条目集，覆盖四维度结论。条目结构见 6.3。
- **可复用 skill**：把四维度的分析方法写成操作手册（取数口径、计算步骤、判定规则），使其他分析人员或 Campaign 可独立复现。
- **迭代机制**：知识库随实操持续扩充；新结论与旧结论冲突时，以"样本量 + 共发动作清理 + 旺季检查"三要素评估可信度，取更严谨者。

## 4. 数据要求

### 4.1 必需数据（渠道 × 周粒度）

| 字段 | 用途 |
| --- | --- |
| 花费（Spend） | CPFL、边际 CPFL、预算消耗分析 |
| Leads 数 | 模块一监控、带宽设定 |
| 完成借款数（Loans） | CPFL、弹性计算 |
| CPFL | 直接监控指标 |
| Green% | 状态诊断字段 |

### 4.2 动作变更日志

| 字段 | 说明 |
| --- | --- |
| 动作类型 | 预算调整、tROAS 变更、转化目标变更、负关键词、Asset 新增、受众信号、暂停 / 启用、着陆页修改 |
| Campaign / 渠道 | 归属 |
| 生效时间 | 至少精确到周 |
| 调整幅度 | 如预算 ±%、tROAS 旧值 → 新值 |

> **完整性要求**：动作日志漏记会导致共发干扰误判（模块二 3.4），是深度分析准确性的前提。

### 4.3 来源与口径

- 来源类型：投放平台后台导出、归因报表、内部数仓（具体表名与取数口径待确认，见第 9 节）。
- 口径要求：CPFL 的分子（成本范围）与分母（完成借款定义）需书面确认并固定；跨来源数据需对齐渠道命名与时间粒度。

## 5. 实施路径

> 以下为建议方案：阶段划分、顺序与验收标准是框架定义；工期为估算假设，需结合团队实际确认。

### 5.1 阶段 0：数据准备（估算 1–2 周）

| 项 | 内容 |
| --- | --- |
| 任务 | 确认取数来源与口径；建立"渠道 × 周"事实表；整理近 52 周历史数据与动作变更日志 |
| 产出 | 数据字典（字段定义 + 口径）、取数脚本、历史数据集 |
| 验收标准 | 可稳定拉取近 52 周渠道 × 周数据；数值与投放平台报表抽验 1–2 个月一致；动作日志覆盖近 52 周且无整段缺失 |

### 5.2 阶段 1：模块一落地（估算 2–3 周）

| 项 | 内容 |
| --- | --- |
| 任务 | 按 2.2 规则计算初版目标带宽 → 与业务经验核对校准 → 搭建 BI 看板（带宽、实际值、状态色自动计算）→ 启动周度监控 |
| 产出 | 分渠道目标带宽表（定版）、状态监控看板、周监控 SOP |
| 验收标准 | 连续 4 周按 SOP 产出看板与差距表；状态判定结果与人工判断无重大分歧（如有分歧，回校阈值与带宽） |

### 5.3 阶段 2：模块二试运行（估算 2–4 周）

| 项 | 内容 |
| --- | --- |
| 任务 | 以 Pmax Value 为样本完成四维度分析（含补齐预算消耗时长维度）→ 定版知识库条目模板 → 把分析过程写成可复用 skill 操作手册 |
| 产出 | 四维度分析报告、知识库条目模板、skill 操作手册 |
| 验收标准 | 四维度均有结论或明确的"样本不足 / 待补充"标注；另一名分析人员能按 skill 手册独立复现（至少复算出一致的结果） |

### 5.4 阶段 3：推广（持续）

| 项 | 内容 |
| --- | --- |
| 任务 | 按消耗规模 / 重要性对 Campaign 排序，逐个复用 skill 完成四维度分析，建立各自知识库条目 |
| 产出 | 核心 Campaign 知识库全覆盖 |
| 验收标准 | 每个核心 Campaign 均有知识库条目；新 Campaign 分析耗时显著低于 Pmax Value 首次分析（建议以"减半"为初始目标，需实际度量后校准） |

### 5.5 阶段 4：持续迭代（长期）

- 周监控中发现误报 / 漏报 → 校准阈值与带宽；
- 知识库随实操扩充；样本数值与业务经验值定期校验；
- **季度校准**：回顾加权系数（0.5/0.3/0.2）、状态阈值（5–15%、1–2σ）、带宽系数，调整须记录理由。

## 7. 边界条件与注意事项

1. **样本单一**：现有结论来自 Pmax Value 单 Campaign、54 周数据，跨 Campaign 需重新计算，不得直接套用。
2. **共发干扰**：任何动作效果分析必须先做共发动作清理（3.4），否则结论易被污染。
3. **旺季效应**：分析需检查旺季集中度，避免单季、异常期样本主导结论。
4. **学习期互斥**：高风险动作（如转化目标变更）不应与其他动作并行，以免干扰归因。
5. **样本量下限**：清理后 n<3 的档位不下结论。
6. **口径一致性**：CPFL 口径一旦固定不得随意变更；变更需记录并重算历史。

## 9. 术语表

| 术语 | 定义 |
| --- | --- |
| CPFL | Cost Per Finished Loan，每完成借款成本 |
| 边际 CPFL | 相邻支出水平间，成本增量 ÷ 完成借款增量（决策指标） |
| 平均 CPFL | 历史累计总成本 ÷ 总完成借款数（参考指标） |
| tROAS | Target Return On Ad Spend，目标广告支出回报率 |
| Green% | 状态判定中的绿色达标占比 |
| 学习期 | 动作上线后至 CPFL 稳定（周环比 <1σ 连续 2 周）所需时长 |
| 共发动作 | 与目标动作同一周内发生的其他调整动作，会产生干扰 |
| 目标带宽 | 渠道目标的低 / 中 / 高区间 |
| CoV | Coefficient of Variation，变异系数（σ / 均值，用于衡量区间宽度） |
| 弹性 | 每多投入 1 美元带来的增量价值比例 |
